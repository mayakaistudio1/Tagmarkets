# Архитектура проекта JetUP Digital Hub

## 1. Обзор
JetUP — это высокотехнологичный цифровой хаб и "умный линктри", реализованный как веб-приложение и Telegram Mini App (TMA). Основная цель — онбординг пользователей в финансовую экосистему JetUP через структурированный контент и AI-ассистентов.

## 2. Основные компоненты

### 2.1. Главный Хаб (`/`)
Центральная точка входа в экосистему.
- **Maria AI**: Интегрированный AI-консультант (текст + видео-аватар HeyGen).
- **Trading Hub**: Раздел о торговых стратегиях (Copy-X, NeoFX) и брокере TAG Markets.
- **Partner Hub**: Информация о партнерской программе, комиссиях и вознаграждениях.
- **Schedule**: Интерактивный календарь вебинаров и Zoom-созвонов (CET/MSK).
- **Tutorials**: База знаний с видео-уроками и PDF-презентациями.
- **Promotions**: Актуальные маркетинговые акции и бонусы.

### 2.2. Персональный Digital Hub (`/p/:slug`)
Персонализированная "умная визитка" партнера.
- **Dennis Schymanietz (Founder)**: Доступен по адресу `/p/dennis`.
- **Digital Twin**: Кнопка запуска персональной цифровой копии (видео-аватар партнера).
- **Direct Contact**: Прямые ссылки на Telegram, WhatsApp и телефон партнера.
- **Ecosystem Integration**: Полный доступ ко всем разделам главного хаба.

### 2.3. Админ-панель (`/admin`)
Управление контентом и аналитика:
- Просмотр и анализ чатов с Maria AI (GPT-4o анализ).
- Управление спикерами и событиями в расписании.
- Редактирование промо-акций.
- Автоматическая генерация рекламных баннеров.

## 3. Техническая реализация
- **Frontend**: React 19, TypeScript, Vite.
- **Backend**: Node.js, Express 5.
- **База данных**: PostgreSQL + Drizzle ORM.
- **AI Стек**: 
    - OpenAI GPT-4o (текстовая логика).
    - HeyGen LiveAvatar (визуализация аватара).
    - LiveKit (WebRTC стриминг).
- **Хранилище**: Replit Object Storage для медиа-файлов.

## 4. Карта переходов
- **Landing (Hub)** -> Выбор продукта -> Форма заявки (Lead Gen).
- **Partner Hub** -> Описание условий -> Презентация (Google Drive).
- **Partner Page** -> Видео-звонок с партнером -> Регистрация по ссылке.
- **Admin** -> Анализ чата -> Оптимизация промптов AI.

## 5. Мультиязычность
Полная поддержка трех языков: **Немецкий (DE)**, **Русский (RU)**, **Английский (EN)**. Язык сохраняется в контексте приложения.
