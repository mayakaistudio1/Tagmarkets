# JetUP — Master Task для branded B-roll / motion graphics по бонусам

## Задача

Подготовить набор branded motion graphic scenes / B-roll assets для 4 бонусов партнёрской программы JetUP, чтобы потом использовать их внутри Video Agent, HeyGen, монтажных шаблонов и коротких вертикальных роликов.

Бонусы:

1. Lot Commissions
2. Profit Share
3. Infinity Bonus
4. Global Pool

Главная идея:
не пытаться заставить Video Agent самому придумывать графику,
а заранее произвести controlled visual assets в стиле JetUP,
которые потом можно миксовать с A-roll аватара.

---

## Общий визуальный принцип

Все графические сцены должны быть выполнены в едином стиле JetUP.

Источник стилистики:

* существующая презентация JetUP
* текущий дизайн-системный стиль
* Figma / брендовые экраны / тёмная premium fintech подача

### Визуальный стиль

* dark premium fintech background
* deep black / dark navy base
* purple and magenta light accents
* white / soft light typography where needed
* thin elegant lines
* glow accents only very controlled
* premium minimalism
* no cheap 3D look
* no random stock imagery
* no crypto-hype style
* no clutter
* no cartoon feeling

### Motion style

* smooth
* elegant
* premium
* diagram-driven
* clean line reveals
* node connections
* soft data-flow movement
* minimal parallax if needed
* subtle light pulses
* cinematic but not flashy

### Format requirements

* vertical 9:16 first priority
* each scene should also be adaptable to crop / reframe
* duration per B-roll asset: 4 to 8 seconds loop-friendly
* every scene should work both with and without text overlays

### Important rule

These assets are not full finished videos.
They are branded visual modules that can later be inserted into avatar videos.

---

## Deliverable structure

For each bonus create 3–4 different branded visual modules.

Each module should include:

* name of the module
* what it visually represents
* motion logic
* optional highlight text zone
* how it can be used in video editing

---

# BONUS 1 — LOT COMMISSIONS

## Core meaning

Доход с торговой активности и объёма внутри структуры.

## Visual module 1 — Deal to Volume to Commission Flow

### Purpose

Показать механику: сделка → объём → комиссия → распределение.

### Visual concept

Темный фон. На экране возникают минималистичные точки / импульсы как отдельные сделки. Они проходят через элегантную flow-line систему, собираются в общий volume stream, после чего часть потока отделяется и уходит вверх / в стороны как commission distribution.

### Motion

* small trade pulses appear
* pulses join into one volume line
* line intensifies softly
* one layer separates into commission branch
* branch distributes across a structure map

### Usage

Идеально для сцены “как работает бонус”.

### Optional highlight text

* Торговая активность
* Объём
* Комиссия

## Общая задача для дизайнера / motion designer / AI visual tool

Create a branded visual asset pack for JetUP covering 4 bonus concepts:
Lot Commissions, Profit Share, Infinity Bonus, and Global Pool.

For each concept, create 3–4 short motion graphic modules in one consistent premium fintech visual system.

The assets must feel like they belong to the same JetUP presentation universe.

Use:

* dark premium backgrounds
* elegant line diagrams
* network maps
* flow-based logic
* structure growth visuals
* result-flow visuals
* subtle premium glow
* minimal typography zones

Avoid:

* generic stock visuals
* clutter
* noisy compositions
* cheap 3D
* flashy crypto style
* cliché finance imagery

The output should be a reusable B-roll library for vertical JetUP partner-program videos.

---

## Как это использовать дальше

После создания этих модулей их можно:

* вставлять между A-roll сценами аватара
* отдавать как reference в Video Agent
* использовать как branded overlays
* анимировать отдельно в Premiere / CapCut / After Effects
* собирать из них разные версии роликов под русский, немецкий и английский языки

Главная цель:
чтобы визуальная часть бонусных роликов перестала зависеть от случайной генерации,
а строилась на заранее подготовленной JetUP visual library.
