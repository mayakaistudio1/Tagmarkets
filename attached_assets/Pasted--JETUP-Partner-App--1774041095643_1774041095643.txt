Проект: JETUP / Partner App — отчёты по мероприятиям.

Цель:
Исправить логику отчётов по прошедшим мероприятиям, чтобы партнёр видел ТОЛЬКО тех участников, которых ОН СДАМ приглашал (через свою уникальную реферальную ссылку), и не видел «walk-in» гостей и участников, пришедших из других источников.

Текущие проблемы (видены в UI):
1. Партнёр видит всех участников мероприятия, включая тех, кто пришёл НЕ через его ссылку (помечены как «Walk-in»).
   - Пример: событие "Экосистема JetUP" показывает 3 участников, из них 0 через ссылку партнёра, но все 3 видны в списке.
   - Парт нер должен видеть только людей, приглашённых через его реферальную ссылку.

2. Неправильные метрики:
   - Конверсия показывает 300% (невозможно > 100%).
   - Средняя длительность показывает 1889 минут (~31 час), что явно неправильно.

3. Контакты отфильтрованы неправильно:
   - В отчёте есть подсекция "Teilgenommen (3) — (0 über deinen Link)" (Участников 3, через твою ссылку 0).
   - Но внизу партнёр видит всех 3 участников в полном списке, хотя не приглашал их.
   - Партнёр должен видеть ПУСТО или только фильтр с надписью «Никто из приглашённых не пришёл».

4. Раздел "Nicht erschienen" показывает людей, которых партнёр приглашал, но они не пришли — это должно быть ВИДНО и учитано в отчёте.

Требуемое поведение:
1. Раздел "Teilgenommen" должен показывать ТОЛЬКО участников, пришедших через ссылку конкретного партнёра.
   - Если никто из приглашённых партнёром не пришёл → показать "Никто из ваших приглашённых не присутствовал" или пусто.
   - Walk-in гости (пришедшие из других источников) → не показывать вообще.

2. Раздел "Nicht erschienen" (Не пришли) — показывать только людей, которых пригласил ЭТОТ партнёр.

3. Метрики конверсии и длительности:
   - Конверсия = (Число участников из ссылки партнёра / Число приглашённых партнёром) × 100%.
   - Если приглашено 0 → конверсия = 0%, не 300%.
   - Длительность → рассчитывать только для людей, которых пригласил партнёр.
     - Если даные неправильные или некорректные → показать прочерк или 0, а не 1889 минут.

4. На странице "Vergangen" (Прошедшие события):
   - Число "TEILGENOMMEN" должно показывать только участников, пришедших через реферальную ссылку партнёра.
   - Walk-in участники НЕ должны учитываться в числе участников партнёра.

Что изменить в коде:
1. Найти логику расчёта метрик в отчёте мероприятия (конверсия, длительность, количество участников).
   - Добавить фильтр: `где participant.referrer_partner_id === current_partner.id` или подобный.
   - Исключить всех walk-in и участников, которых не приглашал этот партнёр.

2. Найти список контактов в отчёте ("Teilgenommen", "Nicht erschienen").
   - Убедиться, что в списке показываются ТОЛЬКО контакты, приглашённые этим партнёром.
   - Walk-in и контакты других партнёров → не показывать.

3. Исправить расчёт конверсии:
   - Если registered_from_partner === 0 → conversion = 0%, не 300%.
   - Если attended_from_partner === 0 → не показывать 3 участников, если ни один не от партнёра.

4. Исправить расчёт средней длительности:
   - Убедиться, что данные Zoom правильно парсятся (1889 минут = явная ошибка).
   - Применить фильтр только для участников этого партнёра.
   - Если данные невалидны → показать N/A или 0.

Проверка результата:
После исправления в отчёте по событию "Экосистема JetUP" (2026-03-18) должно быть:
- "Teilgenommen (0)" — вместо "Teilgenommen (3)", потому что из твоих приглашённых никто не пришёл.
- Или "Teilgenommen (1)" — если один из твоих приглашённых всё же пришёл.
- Конверсия должна быть ≤ 100% и логически корректна.
- Длительность должна быть реальной (не 1889 минут) или показывать N/A.
- Список контактов в отчёте должен быть ПУСТЫМ или показывать только твоих приглашённых.

Примеры сценариев:
1. Партнёр пригласил 2 человека, оба пришли → Teilgenommen (2), Conversion 100%.
2. Партнёр пригласил 4 человека, 1 пришёл, 3 не пришли → Teilgenommen (1), Nicht erschienen (3), Conversion 25%.
3. Партнёр не приглашал никого, но 5 walk-in пришли → для партнёра: Teilgenommen (0), Conversion 0%, Walk-in не отображаются.

Стиль:
- Сначала покажи, где в коде лежит логика фильтрации и расчётов метрик.
- Затем предложи конкретные изменения с объяснением.
- Не ломай существующие фильтры для админа или других представлений — меняй только то, что видит партнёр.
- Если нужны миграции данных или переиндексация — предупреди и объясни, почему.
