# JetUP — Copy-Paste Prompt для HeyGen Video Agent

Create a series of 5 short vertical videos in Russian for the JetUP Partner Program.

The videos must feel like one unified premium fintech content series.

## General Requirements

* Create 5 separate videos, not one combined video
* Language: Russian
* Format: 9:16 vertical
* Duration of each video: 40–60 seconds
* Presenter: professional female avatar
* Use both A-roll and B-roll
* A-roll = avatar explains clearly and confidently
* B-roll = controlled abstract finance visuals, clean motion graphics, structure diagrams, flow diagrams, growth visuals, elegant UI-style overlays

## Style Requirements

The whole series must look premium, modern, minimal, and trustworthy.

Visual style:

* premium fintech aesthetic
* dark background
* purple and magenta accents
* white typography
* elegant motion graphics
* smooth premium transitions
* high contrast readability
* clean composition
* cinematic but minimal

Tone of voice:

* clear
* structured
* confident
* calm
* premium
* easy to understand
* suitable for leaders, partners, and financially-oriented audience

## Strict Visual Restrictions

Do NOT use:

* generic office footage
* random business people in offices
* handshake clichés
* overdramatic stock footage
* flashy crypto visuals
* noisy or chaotic motion graphics
* cheap-looking animations
* too many numbers on screen at once
* unrealistic wealth visuals
* luxury clichés like sports cars, watches, mansions, private jets

Prefer instead:

* abstract finance-themed visuals
* structure growth diagrams
* commission flow diagrams
* profit flow diagrams
* elegant network maps
* layered architecture visuals
* premium motion overlays
* minimal text emphasis
* high-end branded explainer style

## Graphic System Requirements

All 5 videos must use one consistent graphic system.

Use the same structure in every video:

* intro title card
* key phrase overlays
* diagram-based explanation visuals
* clean lower-third style if needed
* closing statement card
* final branded end screen

Use unified visual language across the series:

* same line thickness
* same arrow logic
* same block shapes
* same spacing logic
* same animation style
* same caption style
* same transition rhythm

## Opening Structure for Every Video

Each video should begin with:

* small top line: JetUP Partner Program
* main title: bonus name or overview title
* short subtitle explaining the meaning

Use these subtitles:

* Lot Commissions — доход с торговой активности
* Profit Share — доход с реального результата
* Infinity Bonus — доход с глубины структуры
* Global Pool — зрелый бонусный слой
* Partner Program — многоуровневая система дохода

## Caption Rules

Captions and on-screen key phrases must be short.

Rules:

* 2 to 5 words when possible
* one idea per phrase
* no long sentences on screen
* support the voiceover, do not repeat everything fully

Examples of acceptable key phrases:

* Торговая активность
* Повторяющийся доход
* Реальный результат
* Рост структуры
* Глубина команды
* Долгосрочная модель
* Зрелый бонусный слой
