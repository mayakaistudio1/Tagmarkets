#45 – Telegram Notifications After Guest Registration (Revised)
What & Why
После регистрации на вебинар гость должен получить подтверждение и напоминания в выбранном канале (Telegram / WhatsApp / Email) — автоматически, без ручных действий партнёра.

Текущая проблема:

Если гость выбирает Telegram, то планировщик напоминаний работает только через @username — но это работает только если гость сначала написал боту.

Если гость не взаимодействовал с ботом раньше, сообщение не доходит (Telegram-ограничение).

Нет единого выбора канала связи на экране регистрации.

Правильное решение:

На экране регистрации гостя добавить выбор канала: Telegram / WhatsApp / Email.

После успешной регистрации, если гость выбрал Telegram, показать CTA-кнопку с deep link на бота: t.me/BotName?start=remind_CODE.

Гость воспринимает это как продолжение своего выбора канала, а не как отдельную «регистрацию у бота».

Когда гость нажимает deep link и открывает бота:

Бот получает chat_id и связывает его с personal_invite по CODE.

Бот присылает подтверждение регистрации (название вебинара, дата, время).

Дальше система может слать любые напоминания без доп. действий.

Планировщик напоминаний использует сохранённый chat_id (надёжно) вместо @username (ненадёжно).

Done looks like

«Как с тобой связаться?» с опциями: Telegram / WhatsApp / Email.

Гость выбирает один из каналов (обязательно).

✅ Для Telegram:

Гость может ввести @username для отображения и fallback (опционально).

После успешной регистрации автоматически показывается большая CTA-кнопка:

«Получить напоминание в Telegram» → deep link t.me/BotName?start=remind_CODE.

Кнопка не блокирует продолжение (гость может пропустить, если не хочет подписываться).

✅ Когда гость нажимает deep link:

Бот обрабатывает /start remind_CODE.

Сохраняет telegramChatId в поле telegram_chat_id таблицы personal_invites.

Сразу присылает подтверждение: название вебинара, дата/время, текст «Мы напомним тебе за 24 часа и за 1 час до старта».

Канал связи: Telegram / WhatsApp / Email.

Статус подписки:

🔔 Подписан на напоминания (для Telegram/WhatsApp — если гость прошёл deep link).

⏺ Не подписан (если гость пропустил кнопку или выбрал Email).

✅ Напоминания отправляются:

За 24 часа до вебинара.

За 1 час до начала.

Планировщик приоритизирует telegram_chat_id над @username.

Логирует успех/неудачу отправки.

Out of scope
WhatsApp-уведомления (отдельная инфраструктура, может быть добавлено позже).

SMS-уведомления.

Push-уведомления в мобильное приложение.

Tasks
Добавить поле выбора канала на PersonalInvitePage

На экране регистрации гостя добавить блок: «Как с тобой связаться?» (Telegram / WhatsApp / Email).

Сохранять выбор в поле preferred_channel таблицы personal_invites.

Для Telegram: опциональное поле ввода @username (для fallback).

Добавить колонку telegram_chat_id в таблицу personal_invites

Добавить миграцию: ALTER TABLE personal_invites ADD COLUMN telegram_chat_id BIGINT NULLABLE;

Добавить колонку preferred_channel (ENUM: telegram, whatsapp, email).

Добавить флаги: telegram_notifications_enabled: BOOLEAN DEFAULT false.

Deep link кнопка на экране после регистрации

После успешной регистрации, если preferred_channel == 'telegram':

Показать большую кнопку: «Получить напоминание в Telegram».

Кнопка содержит deep link: https://t.me/BotName?start=remind_CODE (где CODE = unique код для personal_invite).

Кнопка не блокирует продолжение (гость может закрыть и перейти на экран мероприятия).

Обработать /start remind_CODE в Partner Bot webhook

В обработчике /start парсить параметр start=remind_CODE.

Если есть CODE:

Найти personal_invite по CODE.

Сохранить chat_id сообщения в personal_invites.telegram_chat_id.

Отправить подтверждение: название вебинара, дата, время, текст напоминания.

Обновить флаг telegram_notifications_enabled = true.

Обновить планировщик напоминаний

При отправке напоминания приоритизировать логику:

Если telegram_chat_id есть → отправить через sendMessage(chat_id, text).

Если нет telegram_chat_id, но есть @username → отправить через sendMessage(@username, text) (fallback).

Логировать: успех/неудачу, какой метод использован, timestamp.

Отправлять напоминания за 24 часа и за 1 час до вебинара.

UI статуса в Mini App партнёра

В карточке контакта показывать:

Канал: Telegram / WhatsApp / Email.

Статус: 🔔 Подписан / ⏺ Не подписан.

Для Telegram: если telegram_notifications_enabled == true → 🔔 Подписан.
