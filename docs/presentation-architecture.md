### Визуальная структура каждого слайда

```
┌──────────────────────────┐
│  [фоновое изображение]   │
│  [gradient overlay]      │
│                          │
│                          │
│  ┌─────┐                 │
│  │icon │  02             │
│  └─────┘                 │
│  Заголовок               │
│  Текст описания          │
│  • Буллет 1              │
│  • Буллет 2              │
│  • Буллет 3              │
└──────────────────────────┘
```

- Фон: изображение из `/images/presentation/`
- Overlay: gradient от акцентного цвета (20-30% opacity) сверху → чёрный (85-90% opacity) снизу
- Контент прижат к низу карточки (`justify-content: flex-end`)
- Иконка: lucide-react, в квадрате 40x40 с полупрозрачным фоном акцентного цвета
- Номер слайда: мелкий, акцентный цвет, формат "01", "02" и т.д.

## Навигация

### Кнопки

- **Назад** (ChevronLeft): переход на предыдущий слайд. Disabled на первом слайде.
- **Далее** (ChevronRight): переход на следующий слайд. Фон — полупрозрачный акцентный цвет текущего слайда.
- **Закрыть** (X): возврат в чат в любой момент.

### Свайп (планируется)

В текущей реализации навигация через кнопки. Для свайпа можно добавить обработчики touch-событий или использовать `framer-motion` drag gesture.

### Анимация переходов

```
Вход (enter):  x: ±280px, opacity: 0, scale: 0.95
Центр (center): x: 0, opacity: 1, scale: 1
Выход (exit):  x: ∓280px, opacity: 0, scale: 0.95
Длительность: 0.35s, easing: easeInOut
```

Направление анимации определяется переменной `direction`:
- `direction = 1` → слайд входит справа, выходит влево (вперёд)
- `direction = -1` → слайд входит слева, выходит вправо (назад)

### Progress bar

Тонкая полоска (3px) в самом верху экрана. Заполняется акцентным цветом текущего слайда. Ширина = `(currentSlide + 1) / totalSlides * 100%`.

## Контрольные точки (Checkpoints) — Режим B

Режим B (интерактивный) активен по умолчанию. Вместо перехода к следующему слайду показывается экран с вопросом и чипами выбора.

### Точка 1 — после слайда 1 (Мечта)

**Вопрос:** «Что ты ищешь сейчас?»

| Чип | Переход на слайд |
|-----|-------------------|
| Пассивный доход | → Слайд 6 (Безопасность) |
| Построение команды | → Слайд 8 (Рентабельность) |
| Понять безопасность | → Слайд 6 (Безопасность) |

### Точка 2 — после слайда 4 (Диагноз)

**Вопрос:** «Что обычно ломается у людей?»

| Чип | Переход на слайд |
|-----|-------------------|
| Нет доверия | → Слайд 6 (Безопасность) |
| Нет системы | → Слайд 9 (Переход) |
| Нет результата | → Слайд 8 (Рентабельность) |

### Точка 3 — после слайда 11 (Простота механики)

**Вопрос:** «Какой следующий шаг тебе удобнее?»

| Чип | Переход |
|-----|---------|
| Показать маркетинг | → Слайд 10 (Партнёрская модель) |
| Войти по ссылке | → Слайд 12 (Выбор) |
| Записаться на звонок | → Слайд 12 (Выбор) |
| Вернуться в чат | → Закрытие презентации, возврат в чат |

### Механика контрольных точек

```
handleNext() {
  1. Проверить: есть ли checkpoint после текущего слайда?
     → checkpoints.find(c => c.afterSlide === current + 1)
  2. Если да → показать checkpoint (setShowCheckpoint)
  3. Если нет → перейти на следующий слайд
}

handleChip(chip) {
  1. Если target === -1 → вызвать onBackToChat()
  2. Иначе → goTo(target - 1)  // target - 1 т.к. индексация с 0
}
```

Визуально checkpoint — это отдельный экран без фонового изображения:
- Glow-эффект (размытый круг акцентного цвета, opacity 8%)
- Вопрос крупным шрифтом (22px, bold)
- Чипы — полноширинные кнопки с иконкой, текстом и стрелкой →
- Кнопка «Пропустить» внизу (переходит на следующий слайд линейно)
- Кнопка «Назад» в навигации (закрывает checkpoint, возвращает к слайду)

## Возврат в чат после презентации

При возврате в чат (любым способом — кнопка X, «Вернуться в чат», или CTA):

1. `PartnerDigitalHub` устанавливает `presentationWatched = true`
2. `ChatOverlay` получает проп `presentationWatched`
3. Через 600ms AI-сообщение добавляется в чат:
   > «Что из этого откликнулось больше всего? Давай разберём твой кейс лично.»
4. Сообщение отправляется один раз (флаг `followUpSent`)

```
HERO
  │
  ├─ [Нажать "Чат"] ──→ CHAT_OVERLAY
  │                        │
  │                        ├─ [2+ сообщения] → AI предлагает презентацию
  │                        │
  │                        ├─ [Нажать "Открыть презентацию"] ──→ PRESENTATION_OVERLAY
  │                        │                                      │
  │                        │     ┌─────────────────────────────────┘
  │                        │     │
  │                        │     ├─ Слайд 1 → [Далее] → Checkpoint 1
  │                        │     │                         ├─ Чип → Слайд 6/8
  │                        │     │                         └─ Пропустить → Слайд 2
  │                        │     ├─ Слайды 2-4 → [Далее] → Checkpoint 2
  │                        │     │                         ├─ Чип → Слайд 6/8/9
  │                        │     │                         └─ Пропустить → Слайд 5
  │                        │     ├─ Слайды 5-11 → [Далее] → Checkpoint 3
  │                        │     │                          ├─ Чип → Слайд 10/12/чат
  │                        │     │                          └─ Пропустить → Слайд 12
  │                        │     ├─ Слайд 12 → CTA кнопки
  │                        │     │
  │                        │     └─ [X / Вернуться в чат] ──→ CHAT_OVERLAY
  │                        │                                   + AI follow-up сообщение
  │                        │
  │                        └─ [X] ──→ HERO
  │
  └─ [Нажать "Live"] ──→ /live (отдельный route)
```

## Тексты слайдов (полный контент)

**Слайд 1 — Мечта:**
Представьте проект, который долгосрочный. Где вы строите большую команду даже на перегретом рынке. Где есть чек, развитие и система дубликации.

**Слайд 2 — Стандарт:**
Идеальный проект должен включать:
- Финансовый продукт, связанный с реальным рынком
- Безопасность капитала
- Возможность вывода средств
- Маркетинг-план
- Систему дубликации

**Слайд 3 — Факты рынка:**
- Финансовые рынки растут
- MLM-индустрия > 650 млрд
- Интерес к пассивному доходу увеличивается

**Слайд 4 — Диагноз:**
- Нет баланса между прибылью и безопасностью
- Нет прозрачности
- Нет системы дубликации
- Всё держится на лидере

**Слайд 5 — Решение:**
JetUP — это экосистема, которая объединяет финансовый продукт и партнёрскую модель в одной структуре.

**Слайд 6 — Безопасность:**
Средства находятся у лицензированного брокера. Контроль остаётся у клиента. Прозрачность операций.

**Слайд 7 — Гибкость:**
Нет жёсткой заморозки. Возможность вывода. Управляемость стратегии.

**Слайд 8 — Рентабельность:**
Баланс доходности и риска. Стратегический подход. Системная модель вместо хайпа.

**Слайд 9 — Переход:**
Даже лучший продукт не масштабируется без системы.

**Слайд 10 — Партнёрская модель:**
Маркетинг-план — потенциал. Результат создаёт инфраструктура.
- Profit Share
- Infinity Bonus
- Global Pools
- Lifestyle Incentives

**Слайд 11 — Простота механики:**
- Человек → продукт
- → партнёрская программа
- → дубликация
- → рост структуры

**Слайд 12 — Выбор:**
Можно продолжать искать идеальный проект.
Можно строить систему в рамках готовой экосистемы.
[CTA: Записаться на созвон / Начать по ссылке / Вернуться в чат]
