# JetUp Partner MiniApp — Dennis (Deck v1)

ТЗ для Replit: визуальная система, экраны, интерактивная презентация (десять слайдов) с чипами-углублениями и чатом.

---

## 0) Цель и принцип

**Цель:** премиальная «цифровая визитка нового поколения» для рекрутинга, где основа — **чат Dennis AI + LiveCall**, а презентация — **интерактивный сторителлинг-deck**.

**Ключевой принцип:**

* Не делаем десять видео.
* Делаем **один общий фон-мир** (единый), и **десять статичных сцен** с персонажем (в одном стиле).
* Анимации — **микро-анимации UI** (карточка/чипы/переходы) + лёгкие частицы/параллакс фона.

---

## 1) Информационная архитектура (экраны)

### Экран A — Hero (без скролла)

**Один экран, помещается в Telegram MiniApp без прокрутки.**

Содержимое:

* Фон: общий «Financial Data Universe» (анимация/частицы, но лёгкая).
* Центр: круглый «портрет/символ Dennis» (или силуэт) + статус.
* Два CTA:

  * **Primary:** «Открыть чат с Dennis AI»
  * **Secondary:** «LiveCall с Dennis (AI Avatar)»
* Мелкая сервисная кнопка (не как основной CTA):

  * **“JetUp Hub / Info & Support”** (открывает основной хаб **оверлеем** поверх визитки, чтобы всегда можно было вернуться назад).

Навигация:

* Primary CTA → экран B (Chat overlay)
* Secondary CTA → экран C (LiveCall)
* Hub → экран D (Hub overlay)

---

### Экран B — Chat (overlay)

**Открывается поверх Hero** (bottom-sheet или full overlay).

Верхние элементы:

* Заголовок: «Dennis AI»
* Подзаголовок: «Founder • Infrastructure & Scale»
* Кнопка: «Пройти интерактивную презентацию» (opens Deck)

Состояния:

* Пользователь может **пропустить Deck** и просто общаться.
* При нажатии на чипы в Deck — чат открывается и отправляет **контекстный intent**.

---

### Экран C — LiveCall (отдельный экран)

* Полноэкранный модуль.
* Кнопка «Назад» возвращает в Hero.
* (Если нет реального live) — показываем статус «готов к разговору», CTA «включить микрофон».

---

### Экран D — JetUp Hub (overlay)

**Очень важно:** это не увод на внешний сайт в текущем UX.
Открываем **внутренним WebView/iframe overlay** (или route внутри Replit) и поверх показываем кнопку:

* «← Вернуться к Dennis Hub» (закрыть overlay)

Смысл:

* Вся “глубокая инфа” (расписание вебинаров, материалы, FAQ, support) — там.
* Но пользователь всегда остаётся в сессии Денниса.

---

### Экран E — Deck (Interactive Presentation)

* Отдельный экран или overlay поверх Hero.
* Внутри: **слайд на весь экран**.
* Текст не в видео — **в UI карточке**.
* Внизу: чипы (2–3) + кнопка «Далее».

Поведение:

* **Чипы не листают слайды.**
* Чип → открывает Chat overlay и задаёт вопрос по текущему слайду.
* «Далее» листает на следующий слайд.

## 2) Визуальная система (единый стиль)

### 2.1 Общий фон (один мир)

**Название:** Financial Data Universe

Описание:

* тёмный премиальный фон
* неоновые потоки данных
* узлы сети
* лёгкие частицы
* тонкие намёки на графики

Требования:

* Единый фон для всех слайдов.
* Лёгкий motion (частицы + медленный drift).
* В идеале: один короткий loop-видео 12–16 сек или CSS/Canvas particles.

Рекомендованный prompt (если генерить фон):

* “Futuristic financial data universe made of glowing purple and blue networks, flowing market data streams, floating abstract charts, cinematic dark fintech atmosphere, slow camera drift, premium minimal aesthetic, vertical nine sixteen, no text.”

---

### 2.2 Персонаж (единый стиль)

**Персонаж:** абстрактная фигура из света/частиц (универсальная)

Почему так:

* не мультфильм
* не привязан к конкретной внешности
* выглядит премиально

Описание:

* “glowing human silhouette made of particles / light”
* мягкий неоновый контур
* без лица или с минимальными чертами

Важно:

* Персонаж один и тот же на всех сценах.
* Меняется поза/сцена, но стиль идентичен.

Рекомендованный prompt (для генерации персонажа/сцен):

* “Minimal cinematic fintech scene, glowing human silhouette made of particles, standing inside a futuristic financial data network, premium dark purple palette, ultra clean, no text, vertical nine sixteen.”

---

### 2.3 Сцены для десяти слайдов (статичные изображения)

Каждый слайд:

* Использует общий фон-стиль
* Добавляет одну «сцену/позицию героя» (изображение)

Сцены:

* Слайд 1: герой смотрит на «живой рынок» (мягкие графики)
* Слайд 2: герой в «хаосе» (разорванные линии/красные импульсы)
* Слайд 3: герой видит “собранную систему” (три слоя соединяются)
* Слайд 4: герой у защищённого узла (щит/контур)
* Слайд 5: герой у развилки (несколько маршрутов)
* Слайд 6: герой идёт по стабильной траектории (ровный рост)
* Слайд 7: сеть расширяется, появляются новые узлы (масштаб)
* Слайд 8: в центре “AI core” (светящийся ядро/бот-символ)
* Слайд 9: сеть-комьюнити (узлы соединяются в структуру)
* Слайд 10: перекрёсток/выбор (две траектории)

## 3) UI / UX требования (mobile-first)

### 3.1 Карточка текста

* Всегда читаема.
* Не зависит от картинки.
* Glass-morphism.

Рекомендованный стиль:

* фон карточки: rgba(12, 6, 25, 0.72)
* blur: 18–24
* radius: 24
* border: 1px solid rgba(255,255,255,0.10)
* тень: мягкая

Размещение:

* По центру или чуть ниже центра.
* Не перекрывать навигацию.

### 3.2 Чипы

* Размещаются **внизу** (под карточкой или в sticky footer).
* 2–3 чипа максимум.
* Tap открывает чат.

Важно:

* Чипы должны относиться к текущему слайду (углубление, примеры, снятие сомнений).

### 3.3 Переходы

* Слайд меняется мягко (fade/slide).
* Карточка появляется с micro-motion.

Рекомендованная анимация:

* opacity: 0 → 1
* translateY: 18px → 0
* scale: 0.98 → 1
* duration: 420–520ms

## 5) Технические требования для Replit (реализация)

### 5.1 Роуты / состояния

* /dennis (Hero)
* /dennis/chat (overlay)
* /dennis/call (screen)
* /dennis/deck (screen)
* /dennis/hub (overlay)

(Можно реализовать как single-page state machine без роутов — но логика должна быть эквивалентной.)

---

### 5.2 Контекстные intents для чипов

Каждый чип отправляет в чат:

* slide_id
* intent
* chip_text

Пример payload:

* { slide_id: 5, intent: "FLEXIBILITY_STOP", chip_text: "Можно ли остановить в любой момент?" }

Требование:

* Ответ Dennis AI **обязан отвечать по текущему слайду**, затем мягко вернуть к предложению «продолжить deck / записаться на созвон».

---

### 5.3 Hub overlay

Hub overlay открывает:

* основной хаб / инфо
* расписание вебинаров
* материалы
* FAQ
* support

Важно:

* overlay всегда имеет кнопку «Вернуться к Dennis Hub».
* при закрытии пользователь возвращается в то место, где был (Hero / Chat / Deck).

---

### 5.4 Оптимизация под Telegram MiniApp

* Все изображения — WebP.
* Lazy-load сцен deck.
* Видеофон (если используется) — один loop, muted, low bitrate.
* Prefer CSS particles/Canvas (если легче) вместо видео.

---

## 6) Definition of Done (критерии готовности)

* Hero помещается без скролла.
* Chat открывается overlay и не ломает layout.
* Deck листается быстро и гладко.
* Чипы всегда открывают чат с **контекстным intent**.
* Hub открывается overlay и всегда есть «назад к Деннису».
* Визуальный стиль единый, премиальный, без перегруза текстом.
