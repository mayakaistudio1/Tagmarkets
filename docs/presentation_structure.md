## Технические детали

### Медиа-ассеты
* Единый видео-фон: `public/videos/financial_universe_bg.mp4` (8s loop, 9:16)
* 10 сцен: `public/images/presentation/scene_01.png` ... `scene_10.png`

### Glassmorphism-карточка
* `background: rgba(12, 6, 25, 0.72)`
* `backdrop-filter: blur(20px)`
* `border-radius: 24px`
* `border: 1px solid rgba(255, 255, 255, 0.10)`

### Чипы
* 2-3 чипа на слайд, каждый с `{ text, intent }`
* Нажатие → открытие чат-панели + отправка текста чипа как сообщение пользователя
* AI-ответ с контекстом текущего слайда (system message injection)

### Анимации
* Карточка: opacity 0→1, translateY 18→0, delay stagger (0.2, 0.3, 0.45)
* Чипы: opacity 0→1, translateY 10→0, delay 0.6
* Переход между слайдами: x ±280, opacity, scale 0.95→1, duration 0.35s
